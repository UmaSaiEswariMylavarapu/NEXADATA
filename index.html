What Is Data Science?

Data Science combines statistics, programming, domain knowledge and analytical thinking to extract useful information from data.

📦

Data

Raw facts and observations collected from different sources. Data can be numbers, text, images, audio or measurements.

Example: Student attendance, examination marks and study hours.
🔍

Analysis

Examining data to identify trends, compare values, investigate questions and understand relationships.

Example: Finding which subject has the highest average marks.
💡

Insights

Useful findings that help people make informed decisions rather than relying only on guesses.

Example: Discovering that students with low attendance may need additional support.
Remember: Data Science does not automatically prove that one thing causes another. A relationship between two variables may have other explanations.

1. Define the Problem

Identify the question, objective and how success will be measured.

Example: Can we identify students who may need extra academic support?

2. Collect Data

Gather relevant data from authorized surveys, databases, files, sensors or other appropriate sources.

Example: Collect study hours, attendance and past marks with appropriate permission.

3. Clean Data

Handle missing values, duplicates, inconsistent formats and incorrect records.

Example: Investigate missing attendance records before analysis.

4. Explore and Analyze

Calculate statistics and use charts to identify patterns, unusual values and possible relationships.

Example: Compare attendance levels with examination scores.

5. Build a Model

When prediction or grouping is needed, select an appropriate algorithm and train it on suitable data.

Example: Train a model using historical student records.

6. Evaluate and Communicate

Check whether results are reliable, explain limitations and communicate findings clearly.

Example: Report prediction errors and explain how the results should be used.

Machine Learning Algorithms

Machine Learning allows computer systems to learn patterns from data. The algorithm should match the task and data available.

📏

Linear Regression

A supervised learning algorithm used to estimate a numerical value from input features.

Example: Estimating a house price from features such as size and location.
🌳

Decision Tree

Uses a sequence of feature-based decisions to make predictions. It can be used for classification and regression.

Example: Classifying a loan application using relevant financial information.
👥

K-Means Clustering

An unsupervised algorithm that divides observations into a chosen number of clusters.

Example: Grouping customers by purchasing patterns.
✉️

Classification

Predicts a category or class using examples with known labels during supervised training.

Example: Classifying an email as spam or not spam.
🧠

Neural Networks

Models made of interconnected computational units. Deep neural networks can learn complex patterns.

Example: Recognizing objects in images.
🎯

Model Evaluation

Measures how well a model performs on appropriate data that was not used to train it.

Example: Using suitable test data to check prediction performance.
Important distinction: Regression usually predicts numerical values. Classification predicts categories. Clustering discovers groups without requiring predefined labels. Always evaluate models before using their predictions in practice.
